[platform infrastructure guide](../agents/release-and-infrastructure.md).

## Candidate release notes

- Durable saved uploads and offline originals, with restart and derived-cache
  recovery checks.
- Curation discard/undo reliability, Family Mode refresh guards, and Creator
  prompt-weight, LoRA selection and enhancement improvements.
- An optional selected-folder Flatpak profile using the native folder chooser.
- Linux HTTP loop-seek, AppImage startup/dependency and external media-helper
  environment repairs.
- Source-built Windows media helpers with retained notices and matching source
  offers; Windows startup recovery guidance when WebView2 is missing.
- Private SVP sidecar ports and managed Python environment isolation. Real SVP
  interpolation and cross-host streaming remain acceptance work.
- GPL-3.0-only application distribution for this release, with historical MIT
  notices retained. Published 2.1.0 and earlier artifacts keep their existing
  licenses. See [licensing](../LICENSING.md).

These notes describe committed work intended for the candidate. They do not
claim every feature is runtime-qualified on every platform.

## Store deferral

The existing distribution owner retains DMC reservation and identity
coordination. Its latest retained observation on 16 November found Microsoft
employment verification still under review, setup disabled and no Windows
product workspace. DMC's production Name, Publisher and PublisherDisplayName
are unavailable. Do not substitute DonutStudio's identity, a development tuple
or the enrollment display label. This blocks the Store route, not preparation
of independent direct-download routes.

## Freeze and promotion checklist

- Review the selected routes, source commit(s), edition, architectures and
  support claims. Keep deferred routes explicit.
- Finish the missing format-specific acceptance; bind each result to the exact
  shipping artifact hash and source. Preserve earlier failures and inspection
  receipts without presenting them as current shipping approval.
- Stage every required binary and matching source companion, plus reviewed
  notices, provenance/association receipts and checksums outside Git. Keep
  private profiles, media, runtime logs, credentials and signing material out
  of source archives and the public preparation record.
- Validate the product-owned profile against the shared core and synchronize
  its required source rows through the distribution workflow. Extend validators
  and destinations before enrolling new package formats; keep publication
  adapters and catalogue/store support distinct from local build support.
- Review the final notes and manifest, confirm the proposed tag is still free,
  then obtain the explicit tag/push/publication authorization required by the
  protocol. Store submission, production signing and announcements remain
  separate actions.
