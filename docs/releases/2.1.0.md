# DonutMediaCenter 2.1.0 — release candidate

This is the first release under the DonutMediaCenter name, formerly LocalBooru.
Existing application IDs, library locations and pairing credentials remain
compatible with the previous application.

## Included work

- Dedicated image, video and music libraries with media-specific navigation,
  directories, filters and collections.
- Donut Create, an optional ComfyUI/DonutNodes v5 creation add-on with simple
  controls, advanced workflow access, editing, history and library output.
- Android local image, video and music indexing, native thumbnails and timeline
  previews, offline playback, and media permission handling.
- Paired server access and streaming, including server-side quality selection
  and SVP streaming fixes.
- Desktop executable/process naming, DMC platform icons, and portable paths and
  Python discovery for managed add-ons.
- Video gallery filename overlays, remembered volume and more responsive
  original-stream seeking.

## Release gates

This document is candidate prose, not a claim that every platform has passed.
Exact artifacts, checksums, source commit and signing certificates must be
recorded before publication. Linux ordinary/SVP playback acceptance, desktop
helper packaging, and native platform launch/upgrade acceptance remain required.
Mac build/CI availability alone does not establish stable Mac support.
Android store submission also requires the store listing, privacy/data-safety
answers, media-permission declarations and account/signing enrollment.
